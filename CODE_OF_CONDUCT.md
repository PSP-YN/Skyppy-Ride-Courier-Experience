# Code of Conduct

## Our standard

Participation in this project is expected to be respectful, constructive, and focused on improving the work. We aim to keep the project welcoming to contributors regardless of experience level, identity, background, or viewpoint.

Examples of expected behavior:
- Use considerate and inclusive language.
- Give actionable feedback about the work, not personal attacks.
- Respect differing experiences and design perspectives.
- Accept reasonable criticism and corrections.
- Focus disagreements on evidence, user needs, and implementation trade-offs.

Unacceptable behavior includes harassment, discrimination, intimidation, personal attacks, doxxing, threats, sexualized attention without consent, and deliberate disruption of discussions.

## Scope

This code applies in repository issues, pull requests, reviews, and other project spaces where someone is representing or participating in this project.

## Enforcement

Project maintainers may edit or remove comments, close discussions, reject contributions, or block participation when behavior violates this code. Reports should be sent privately to the repository owner through their GitHub profile: https://github.com/PSP-YN. Do not post private information in a public issue.
